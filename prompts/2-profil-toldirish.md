# Profilni to‘ldirish

`profile.md` ichidagi bo‘limlarni o‘zingiz haqingizdagi to‘g‘ri ma’lumotlar bilan to‘ldiring.
Parol, token, karta, uy manzili yoki tasdiqlash kodlarini yozmang.

1. Ismingiz, ish/o‘qish va umumiy qiziqishlaringizni yozing.
2. Qaysi tillarda yozishingiz, sen/siz ishlatishingiz, smayllar va odatiy so‘zlaringizni tushuntiring.
3. O‘zbekcha, ruscha va inglizcha odatiy xabarlaringizdan 3–5 tadan namuna qo‘shing.
4. Tez-tez so‘raladigan savollar va o‘zingiz ishlatadigan javoblarni yozing.
5. Bot muhokama qilmasligi kerak bo‘lgan mavzularni belgilang.
6. Avval PREVIEW loglaridagi javoblarni tekshiring va uslubni yaxshilang.

Lokal rejimda profil har javob oldidan o‘qiladi. Railway uchun o‘zgarishni private GitHub
repo’ga commit + push qiling. Profilni faqat egasi tasdiqlagan faktlar bilan to‘ldiring.
